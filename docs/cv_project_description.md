# Retail Sales Analytics — portfolio project

- Developed reproducible Python scripts to generate and profile 5,000 synthetic Sri Lankan retail order lines, with CSV data covering nine regions and four sales channels.
- Calculated revenue, product-cost profit and order metrics from the CSVs, documenting five synthetic-data findings and three business recommendations.
- Prepared Power Query scripts, 15 DAX measures, a report theme and star-schema specifications for three Power BI pages; Desktop implementation and validation remain pending.
